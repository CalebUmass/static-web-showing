Using the viewer

Loading a model
Models stay as still images until picked, so the page opens quickly. Pick one to load the interactive viewer in place.
Moving a model
Drag to rotate, scroll to zoom, right-drag or two fingers to pan.
Filters
Picking two tags in the same group widens the results; picking tags in different groups narrows them. Search applies on top.
Tags on a card
Clicking one filters the collection by it.
