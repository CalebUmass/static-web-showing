Using the archive

Search
Matches titles, notes and every tag on a record.
Filters
Picking two tags in the same group widens the results; picking tags in different groups narrows them. The number beside a tag is how many records would remain if it were added.
Combining
Search, filters and the year range all apply at once.
Tags on a card
Clicking one filters the archive by it.
Viewer
Arrow keys move between drawings, Escape closes. Full resolution downloads the original scan, which can be very large.
